# Анализ уязвимостей по файлу зависимостей
Скрипт для анализа уязвимостей ПО написанного на языках: GO

## Установка

```
git clone git@github.com:it-util/dep-analysis.git

python3 -m venv .venv

pip install -r requirements.txt
```

## Запуск и использование

```
python3 main.py --path <path_to_file>
```

Путь до файла с зависимостями можеть быть как относительным, так и абсолютным

## Получение отчета

Отчет выгружается в туже дерикторию, в которой находится проект. Отчет в формате pdf, название файла vulnerability_report.pdf
